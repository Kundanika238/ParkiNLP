About ParkiNLP

A speech analysis platform for language-based Parkinson's classification.

ParkiNLP analyzes spoken language by combining Whisper transcription, natural language processing, speech-quality assessment, and machine learning to produce an interpretable classification result.

01

What is ParkiNLP?

ParkiNLP is a browser-based speech analysis platform that combines automatic speech transcription, natural language processing, reliability analysis and machine learning.

02

Why NLP?

Instead of treating speech only as an acoustic signal, ParkiNLP explores the linguistic structure contained in the resulting transcript.

Technology

How the platform is built.

ASR

Whisper

Speech recordings are converted into transcripts using the Whisper speech recognition pipeline.

NLP

Linguistic Features

The transcript is transformed into a compact set of selected NLP characteristics.

ML

Classification

The deployment model uses the selected linguistic features to produce an exploratory classification output.

Responsible Use

Designed for responsible use, not diagnosis.

ParkiNLP is an experimental speech-analysis application. A model prediction is not a clinical diagnosis and should not be used to make medical decisions. The purpose of the platform is to demonstrate and investigate a reproducible speech-to-NLP-to-model workflow and to provide a foundation for future research and validation.

Future Improvements

Built to grow with new features.

The current implementation provides a foundation for future experiments involving larger datasets, additional linguistic features, external validation and more robust model evaluation.

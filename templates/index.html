The Approach

From speech to interpretable linguistic evidence.

ParkiNLP transforms recorded speech into measurable linguistic characteristics and evaluates them using a stability-aware machine learning workflow.

01

Speech Processing

Recorded speech is transcribed using Whisper, creating the textual representation required for downstream linguistic analysis.

02

NLP Analysis

Linguistic characteristics such as filler usage, sentence structure, and lexical diversity are extracted from the transcript.

03

Interpretable ML

Stable linguistic features are evaluated using machine learning and cross-validation rather than relying only on a single train-test split.

How ParkiNLP Works

From spoken audio to interpretable results.

ParkiNLP converts spoken audio into text, extracts linguistic characteristics, evaluates speech quality, and produces an interpretable machine-learning classification result.

01

Project Goal

ParkiNLP uses linguistic characteristics derived from speech transcripts to build an interpretable machine- learning classification workflow for Parkinson's-related speech analysis.

Motivation

Why speech and language?

Speech can contain information about how a person uses language, including lexical diversity, sentence structure and filler usage. ParkiNLP investigates these characteristics through a reproducible NLP pipeline.

01

Speech

The system accepts a natural spoken sample recorded directly through the browser.

02

Language

Whisper converts the recorded speech into a textual representation for linguistic analysis.

03

Machine Learning

Selected linguistic features are supplied to the ParkiNLP classification model.

System Architecture

From speech to model output.

01

Browser Recording

The user records a continuous speech sample through the browser microphone.

02

Whisper

The recorded audio is converted and processed to generate the speech transcript.

03

NLP Features

Linguistic characteristics are extracted from the generated transcript.

04

Reliability

The system evaluates whether the speech sample is sufficiently similar to the training distribution before allowing model prediction.

05

Classification

The selected linguistic features are passed to the trained ParkiNLP model.

06

Interpretation

The application presents the prediction, probabilities, transcript, features and reliability information together.

Linguistic Representation

Five selected NLP features.

The current deployment model operates on a compact set of linguistic characteristics.

Filler Count Number of detected filler expressions
Short Sentence Ratio Proportion of short sentences
Type-Token Ratio Lexical diversity measure
Sentence Count Number of detected sentences
Filler Rate Filler usage relative to speech text
Speech Quality & Reliability

Not every speech sample should be treated equally.

ParkiNLP compares the extracted linguistic profile with the feature distribution observed during training. The system can therefore identify samples that may not provide a suitable model input.

NORMAL

Reliable

The sample satisfies the required text and feature conditions.

CAUTION

Caution

Some characteristics differ from the typical training distribution.

LOW

Low Reliability

The system can prevent model prediction when the speech sample does not contain sufficient information.

Limitations

What the current system does not claim.

ParkiNLP is an experimental speech-analysis application. Its output should not be interpreted as a medical diagnosis or as a replacement for professional clinical assessment. Model performance can also depend on recording quality, speech content, transcription quality, dataset characteristics and the representativeness of the training population.
